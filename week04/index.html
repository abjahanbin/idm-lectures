Shaders

Shader: a small program that runs on the GPU, once per pixel (or vertex), to decide color/position.
Not "a texture file" — it's a function.

Procedural: generated by rules/math at runtime instead of stored as fixed data. A procedural texture has no image file behind it — it's computed fresh every frame.

shaders are how you compute a procedural texture in real time
